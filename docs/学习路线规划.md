# 转专业后学习路线规划

> 时间：2026年6月 — 大二结束  
> 专业：通信工程（信息工程学院）  
> 目标：打好编程基础、冲刺雅思、参加智能车竞赛

---

## 第一阶段：期末冲刺（6月8日 ~ 7月初）

当前首要任务是稳住绩点，刚转了专业，成绩单不能掉。

| 科目 | 优先级 | 建议 |
|------|--------|------|
| 高等数学 | 🔴 首要 | 期末考试直接关系到绩点，全力冲刺 |
| 线性代数 | 🔴 首要 | 通信工程对线代要求高（信号处理基础），趁期末打牢 |
| 大学物理 | 🔴 首要 | 电路原理、模电的前置课，不能松懈 |
| CET6 | 🟡 重要 | 每天刷一套听力/阅读真题，背作文模板 |
| C语言 | 🟢 保持手感 | 每天不用超过1小时，当放松 |

---

## 第二阶段：暑假黄金期（7月初 ~ 9月）

暑假是拉开差距的关键时期。三个月的自由时间，需要系统性地提升。

### 主线一：C语言进阶（2~3周）

当前已掌握：循环、数组、字符串、多组输入输出、简单排序、画图

暑假需要补的内容：

```
指针       → 指针基础、指针与数组、函数指针、二级指针、动态内存分配
结构体     → 结构体定义、结构体数组、结构体指针、typedef
链表       → 单向链表、双向链表、增删改查
枚举与共用体 → enum、union 的基本使用
文件操作   → fopen / fclose / fread / fwrite / fprintf / fscanf
预处理     → #define、条件编译、头文件守卫
常用算法   → 二分查找、链表反转、栈与队列的数组/链式实现
```

**每天投入：2 ~ 3 小时**  
**练习平台：洛谷（普及- ~ 普及难度）**  
**重点攻克：指针和结构体**——这是后续所有编程进阶的基石

### 主线二：智能车竞赛入门（贯穿整个暑假）

全国大学生智能汽车竞赛（智能车竞赛）主要用 **STM32 单片机**，语言是 C。  
通信工程做智能车有天然优势——信号处理、传感器融合、PID 控制都是通信的看家本领。

**学习路线：**

```
第1步：买一块 STM32 开发板（推荐 STM32F103C8T6，几十元）
       配套：ST-Link 下载器、面包板、杜邦线、LED、按键

第2步：搭建开发环境
       Keil MDK 或 STM32CubeIDE
       学会编译、下载、调试

第3步：基础外设（1周）
       GPIO 输出（点灯）、输入（按键）
       定时器、PWM（控制电机速度）
       外部中断

第4步：通信协议（1周）
       串口 USART（与电脑通信，打印调试信息）
       I2C / SPI（与传感器通信）

第5步：传感器驱动（1~2周）
       编码器（测速）
       红外传感器 / 摄像头模块
       OLED 显示屏

第6步：控制算法（1周）
       PID 控制（位置式PID、增量式PID）
       电机闭环控制
```

**每天投入：1 ~ 2 小时**  
**关键节点：** 第一次点灯、第一次让电机转起来、第一次用 PID 控速——每过一个节点都会上瘾。

### 主线三：C++ 入门（2周）

通信工程大二要学《面向对象C++编程B》，暑假提前上手。

```
C++ 基础     → cin / cout、string、引用、函数重载、默认参数
面向对象     → 类与对象、构造函数/析构函数、封装、继承、多态
STL 入门     → vector、string、sort、map（竞赛神器）
```

**每天投入：1.5 小时**  
**重点：** 理解"类"的概念——万物皆对象。

### 主线四：数学预习（碎片时间）

通信工程大二大三的核心课对数学要求很高：

| 课程 | 对应数学基础 | 建议预习方向 |
|------|------------|------------|
| 信号与系统 | 复变函数、积分变换 | 傅里叶变换、拉普拉斯变换的概念 |
| 通信原理 | 概率论、随机过程 | 概率密度、期望、方差 |
| 数字信号处理 | 线性代数、复变函数 | DFT/FFT 的基本概念 |

**每天投入：30 分钟**，不需要深钻，翻翻教材对核心概念有个印象就行。

## 第三阶段：大二上（9月 ~ 次年1月）

### 学期内任务

| 优先级 | 任务 | 说明 |
|--------|------|------|
| 🔴 首要 | 专业课 | 模拟电子技术、电路原理、复变函数、信号与系统、C++ |

| 🟢 辅助 | 雅思准备 | 周末背单词、刷听力，为下学期冲刺做准备 |

```

智能车竞赛  → 寒假是调试的黄金期，全力备赛
C++ 进阶   → 如果暑假没学完，寒假补上
```

## 暑假每日时间表示例

```
上午（3h）    C语言进阶（指针、结构体、链表）
```

## 关键资源清单

**C语言进阶：**
- 《C Primer Plus》——指针和结构体讲得最清楚
- 洛谷：普及- ~ 普及 题库

**STM32 / 智能车：**
- 正点原子 / 野火 STM32 教程
- 某宝搜 "STM32F103C8T6 最小系统板"（20元左右）
- B 站：逐飞科技（智能车竞赛专业户）

**C++ 入门：**
- 《C++ Primer》前 8 章
- 洛谷 / Codeforces（用 STL 刷题）

**雅思：**
- 剑桥真题 10~18
- 雅思哥（口语题库）
- 听力：每日英语听力 App

---

> **一句话总结暑假：** 指针结构体打底 → STM32 动手做车 → C++ 面向对象入门 → 数学概念铺垫。  
> 按这个节奏走，到大二开学，你的编程水平会是班上第一梯队，智能车竞赛也能顺利起步。
