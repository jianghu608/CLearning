### 🔥 第一步（6月1日今晚）：for 循环 + 一维数组 — 约 2h

**最低门槛**，不学则任何一题都做不了。

```c
// for 循环标准结构
for (int i = 0; i < n; i++) {
    // 循环体
}

// 数组基本操作
int arr[105];           // 定义数组
for (int i = 0; i < n; i++) {
    scanf("%d", &arr[i]);  // 读入
}

// 遍历求和
int sum = 0;
for (int i = 0; i < n; i++) {
    sum += arr[i];
}

// 找最大值
int max = arr[0];
for (int i = 1; i < n; i++) {
    if (arr[i] > max) max = arr[i];
}
```

strcmp(s1, s2) == 0            // 比较相等

// 遍历字符串每个字符

}

## 四、应试技巧

1. **先读所有题，从最简单的开始做**
   - 先拿前 2 题的满分，保底
   - 中间题尽量拿，最后一题拿部分分

2. **看样例理解题意**  
   普及题大多数是"直接模拟"，题目怎么说你怎么写，不要想复杂

3. **注意多组数据输入**
   ```c
   while (scanf("%d", &n) != EOF) {
       // 处理每组数据
   }
   ```

4. **数据类型注意**
   - 数据范围大时用 `long long`（`%lld`）
   - 数组开大一点：题目说 ≤ 1000，开 `arr[1005]`

5. **每道题先写注释再写代码**（提纲挈领）

6. **测试样例通过后，再想想边界情况**
   - n = 1 的情况
   - 最大值、最小值
   - 空字符串
