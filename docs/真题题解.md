## 题目1 — 简单输出

**题意**：输出 `\\Celebrating the 70th anniversary of Zhejiang University of Technology!//`

**考点**：转义字符。反斜杠 `\` 在 C 语言的字符串中是转义引导符，需要写成 `\\` 才能输出一个 `\`。

**题解**：

```c
#include <stdio.h>

int main(void) {
    printf("\\\\Celebrating the 70th anniversary of Zhejiang University of Technology!//\n");
    return 0;
}
```

> 注意：字符串中两个连续反斜杠 `\\\\`，第一个转义第二个，第三个转义第四个，最终输出两个 `\`。

## 题目2 — 时间解析

**题意**：输入形如 `H22M23S55` 的字符串，解析出时、分、秒，按 `H:M:S` 格式输出。若时间非法（不满足 24 小时制），输出 `Error`。多组数据。

**考点**：
- 字符串解析（从字符串中提取数字）
- `sscanf` 或逐字符解析
- 合法性校验（0 ≤ H ≤ 23, 0 ≤ M ≤ 59, 0 ≤ S ≤ 59）
- 多组数据输入直到 EOF

**题解**：

```c
#include <stdio.h>

int main(void) {
    char str[20];

    while (scanf("%s", str) != EOF) {
        int h, m, s;
        sscanf(str, "H%dM%dS%d", &h, &m, &s);

        if (h >= 0 && h <= 23 && m >= 0 && m <= 59 && s >= 0 && s <= 59) {
            printf("%d:%d:%d\n", h, m, s);
        } else {
            printf("Error\n");
        }
    }

    return 0;
}
```

**也可以用手动解析的方式**（更底层，但同样常用）：

```c
#include <stdio.h>

int main(void) {
    char str[20];

    while (scanf("%s", str) != EOF) {
        int h = 0, m = 0, s = 0;
        // 跳过 'H' 读数字
        int i = 1;
        while (str[i] >= '0' && str[i] <= '9') {
            h = h * 10 + (str[i] - '0');
            i++;
        }
        // 跳过 'M'
        i++;
        while (str[i] >= '0' && str[i] <= '9') {
            m = m * 10 + (str[i] - '0');
            i++;
        }
        // 跳过 'S'
        i++;
        while (str[i] >= '0' && str[i] <= '9') {
            s = s * 10 + (str[i] - '0');
            i++;
        }

        if (h >= 0 && h <= 23 && m >= 0 && m <= 59 && s >= 0 && s <= 59) {
            printf("%d:%d:%d\n", h, m, s);
        } else {
            printf("Error\n");
        }
    }

    return 0;
}
```

## 题目3 — 13的倍数判定（截尾倍比法）

**题意**：把一个整数的个位截去，余下的数加上个位的 4 倍，重复此过程直到结果为 13、26、39 之一或 20 以内的非 13 倍数。输出转换序列，若最终结果是 13 的倍数（13、26、39）则输出 `yes`，否则输出 `no`。

**考点**：
- 循环与数字分解（取个位、截去个位）
- 多组数据处理
- 循环终止条件的判断

**题解**：

```c
#include <stdio.h>

int main(void) {
    int n;

    while (scanf("%d", &n) != EOF) {
        int cur = n;
        int first = 1;

        while (1) {
            if (!first) {
                printf(",");
            }
            printf("%d", cur);
            first = 0;

            // 终止条件：13、26、39 之一
            if (cur == 13 || cur == 26 || cur == 39) {
                printf(" yes\n");
                break;
            }
            // 终止条件：20以内且不是13的倍数
            if (cur <= 20) {
                printf(" no\n");
                break;
            }

            // 截尾倍比变换：截去个位 + 个位 * 4
            int last_digit = cur % 10;
            cur = cur / 10 + last_digit * 4;
        }
    }

    return 0;
}
```

**示例运行**（输入 16354）：
```
16354,1651,169,52,13 yes
```

## 题目4 — 空心菱形

**题意**：给定高度 n（5 ≤ n ≤ 30）和一个字符，输出由该字符构成的空心菱形。注意每组输出之间有一个空行。

**考点**：
- 嵌套循环控制输出格式
- 图形规律归纳
- 输出格式控制（每组输出之间空行）

**思路**：菱形由上下两个 V 形（正三角 + 倒三角）组成，共 2n 行。

**规律**（以高度 n，字符 ch 为例）：
- 上半部分第 i 行（i 从 1 到 n）：
  - 先输出 n-i 个空格
  - 然后输出字符部分：
    - i == 1：1 个字符
    - i == 2：3 个字符（全填充）
    - i ≥ 3：2 个字符 + (2×i-5) 个空格 + 2 个字符
- 下半部分是上半部分的对称（去掉尖，共 n 行）

**题解**：

```c
#include <stdio.h>

int main(void) {
    int n;
    char ch;
    int case_count = 0;

    while (scanf("%d %c", &n, &ch) != EOF) {
        // 每组输出之间空一行（但第一组前不需要）
        if (case_count > 0) {
            printf("\n");
        }
        case_count++;

        // 上半部分（正V）：n 行
        for (int i = 1; i <= n; i++) {
            // 输出前导空格
            for (int j = 1; j <= n - i; j++) {
                printf(" ");
            }

            if (i == 1) {
                // 第一行：1 个字符
                printf("%c\n", ch);
            } else if (i == 2) {
                // 第二行：3 个字符（实心）
                printf("%c%c%c\n", ch, ch, ch);
            } else {
                // 第 i 行（i ≥ 3）：2 个字符 + 空格 + 2 个字符
                int spaces = 2 * i - 5;
                printf("%c%c", ch, ch);
                for (int j = 1; j <= spaces; j++) {
                    printf(" ");
                }
                printf("%c%c\n", ch, ch);
            }
        }

        // 下半部分（倒V）：n 行
        for (int i = n; i >= 1; i--) {
            if (i == 1 || i == 2) {
                continue;   // 去掉尖（第一行）和第二行（因为上半部分已经输出过对称行）
            }

        }
    }

    return 0;
}
```

**正确题解**：

```c
#include <stdio.h>

int main(void) {
    int n;
    char ch;
    int case_count = 0;

    while (scanf("%d %c", &n, &ch) != EOF) {
        // 每组输出之间空一行（第一组前不空）
        if (case_count > 0) {
            printf("\n");
        }
        case_count++;

        // === 上半部分：正V，共 n 行 ===
        for (int i = 1; i <= n; i++) {
            // 前导空格
            for (int j = 1; j <= n - i; j++) {
                printf(" ");
            }

            if (i == 1) {
                printf("%c\n", ch);
            } else if (i == 2) {
                printf("%c%c%c\n", ch, ch, ch);
            } else {
                // 2个字符 + (2*i-5)个空格 + 2个字符
                int spaces = 2 * i - 5;
                printf("%c%c", ch, ch);
                for (int j = 1; j <= spaces; j++) {
                    printf(" ");
                }
                printf("%c%c\n", ch, ch);
            }
        }

        // === 下半部分：倒V，共 n-1 行（去掉最尖的一行）===
        // 下半部分第 k 行对应上半部分第 n-k+1 行的形状
        // 但从 i = n-1 开始到 i = 1（跳过 i=1 即尖）
        for (int i = n - 1; i >= 1; i--) {
            // 前导空格
            for (int j = 1; j <= n - i; j++) {
                printf(" ");
            }

            if (i == 1) {
                printf("%c\n", ch);
            } else if (i == 2) {
                printf("%c%c%c\n", ch, ch, ch);
            } else {
                int spaces = 2 * i - 5;
                printf("%c%c", ch, ch);
                for (int j = 1; j <= spaces; j++) {
                    printf(" ");
                }
                printf("%c%c\n", ch, ch);
            }
        }
    }

    return 0;
}
```

## 题目5 — 整理高手（鸡尾酒排序 / 双向冒泡排序）

**题意**：实现一种特殊的排序方法——每轮整理由两趟构成：
1. 从左到右遍历，相邻比较，逆序则交换 → 最大元素放到末尾
2. 从右到左遍历，相邻比较，逆序则交换 → 最小元素放到开头
3. 缩小范围，重复直到有序
4. 输出每次完整整理后的序列

**考点**：
- 排序算法实现（鸡尾酒排序）
- 循环与交换
- 输出格式控制（逗号分隔）

**题解**：

```c
#include <stdio.h>

int main(void) {
    int n;

    while (scanf("%d", &n) != EOF) {
        int a[105];
        for (int i = 0; i < n; i++) {
            scanf("%d", &a[i]);
        }

        int left = 0, right = n - 1;

        while (left < right) {
            // === 第一趟：从左到右，把最大值移到 right 位置 ===
            for (int i = left; i < right; i++) {
                if (a[i] > a[i + 1]) {
                    int tmp = a[i];
                    a[i] = a[i + 1];
                    a[i + 1] = tmp;
                }
            }
            right--;

            // === 第二趟：从右到左，把最小值移到 left 位置 ===
            for (int i = right; i >= left; i--) {
                if (a[i] > a[i + 1]) {
                    int tmp = a[i];
                    a[i] = a[i + 1];
                    a[i + 1] = tmp;
                }
            }
            left++;

            // === 输出本次整理后的结果 ===
            for (int i = 0; i < n; i++) {
                if (i > 0) printf(",");
                printf("%d", a[i]);
            }
            printf("\n");
        }
    }

    return 0;
}
```

**校验**：
输入：
```
6
3 2 5 4 7 1
4
999 888 777 666
```

第 1 组：
- left=0, right=5
  - 第一趟 (i=0→4): 2,3,4,5,1,7 → right=4
  - 第二趟 (i=4→0): 1,2,3,4,5,7 → left=1
  - 输出：1,2,3,4,5,7
- left=1, right=4
  - 第一趟 (i=1→3): 全部有序无交换 → 结束

输出：`1,2,3,4,5,7` ✅

第 2 组：
- left=0, right=3
  - 第一趟 (i=0→2): 888,777,666,999 → right=2
  - 第二趟 (i=2→0): 666,888,777,999 → left=1
  - 输出：666,888,777,999
- left=1, right=2
  - 第一趟 (i=1→1): 666,777,888,999 → right=1
  - 第二趟 (i=1→1): 无交换 → left=2
  - 输出：666,777,888,999

输出：
```
666,888,777,999
666,777,888,999
```
与样例一致 ✅

## 转专业机考注意事项

### 1. 做题策略
- **先读所有 5 道题**，从最简单的开始做（通常是题1和题2）
- **前 2 题必须全拿**，这是保底分
- **中间题（题3/4）争取 AC**，这两题考的是模拟和图形输出，套路固定
- **最后一题（题5）拿部分分**，写出基本逻辑、能跑出样例即可
- 卡住超过 15~20 分钟就跳下一题，不要死磕

### 2. C 语言应试注意
- **多组数据**：所有题目几乎都是多组输入，`while (scanf(...) != EOF)` 是标配
- **输出格式**：严格按题目要求的格式输出，多一个空格或少一个换行都会判错。题4特别提到"每个输出之间有空行"，注意第一组前不要空行
- **数组开大一点**：n < 100 就开 105，留余量
- **变量初始化**：尤其是累加器、计数器，记得赋初值 0
- **检查边界**：n=1 的情况、最大值、最小值、空输入等

### 3. 考试环境准备
- 确认 IDE 或编辑器可用（Dev-C++ / VS Code / Code::Blocks）
- 确认编译命令：`gcc -std=c11 -o 文件名 文件名.c`
- 学会用 OJ 系统提交代码、查看评测结果

### 4. 冲刺建议
- 还有两天时间，重点练：**多组数据输入输出、字符串解析、数组遍历、图形打印、简单排序**
- 洛谷推荐练习：P1059（排序去重）、P2141（枚举）、P1307（数字反转）、P5727（冰雹猜想）、P5734（字符串处理）
- 不要追求一次写出完美代码，先跑通样例，再处理边界
