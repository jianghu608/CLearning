# 📝 转专业机考模拟卷

> 题型：5 道题，从易到难  
> 时间：建议 120 分钟  
> 语言：C 语言

---

## 题目一览

| 题号 | 题目 | 难度 | 考点 |
|------|------|------|------|
| A | 幸运祝福 | ⭐ | 转义字符、printf |
| B | 日期合法性 | ⭐⭐ | 条件判断、闰年 |
| C | 空心梯形 | ⭐⭐⭐ | 嵌套循环、画图 |
| D | 分数排名 | ⭐⭐⭐ | 数组、排序、查找 |
| E | 单词反转 | ⭐⭐⭐⭐ | 字符串处理 |

---

## 做题建议

1. **从 A 到 E 顺序做**，遇到卡住超过 15 分钟先跳下一题
2. 前 3 题争取全对（对应真题的"进面线"）
3. 每题都注意**多组数据输入**，这是浙工大真题的惯例
4. 写完样例后，自己想一个边界测试一下
